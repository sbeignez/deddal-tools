## Font Configuration

Fonts are mapped to languages in `config/framing_config.json` under `styles.text_defaults`.

Each language specifies:
- `title.font` - Font used for screenshot titles
- `subtitle.font` - Font used for screenshot subtitles

Both title and subtitle use the same Bold weight font for consistency.
