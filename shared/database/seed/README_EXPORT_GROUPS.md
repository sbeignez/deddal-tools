# Export Recognition Groups from Supabase

This guide explains how to sync recognition groups from the Supabase database to local JSON seed files.

## Prerequisites

1. **Python 3.x** installed
2. **Supabase Python client** installed:
   ```bash
   pip install supabase
   ```

3. **Supabase Service Key** - You'll need to get this from your Supabase project dashboard

## Getting the Supabase Service Key

1. Go to [Supabase Dashboard](https://supabase.com/dashboard)
2. Navigate to your project: `qoglsyykgrqalsemigii`
3. Go to **Settings** → **API**
4. Copy the **service_role** key (NOT the anon key)
   - ⚠️ **Security Warning**: This key has full database access - keep it secret!

### Step 3: Review and Confirm

The script will:
1. Fetch all recognition groups from Supabase `lib_cases` table
2. Show a count and sample of groups found
3. Ask for confirmation before updating files
4. Update each JSON case file with groups from the database
5. Display a summary report

The script updates these JSON files in `/Deddal/Data/Resources/SeedData/`:

- `3x3_cfop_f2l_cases.json`
- `3x3_cfop_oll_cases.json` (already has groups, will be refreshed)
- `3x3_cfop_pll_cases.json`
- `3x3_cfop_pcll_cases.json`
- `3x3_cfop_oell_cases.json`
- `2x2_ortega_oll_cases.json`
- `2x2_ortega_pbl_cases.json`
- `3x3_lbl_cases.json`

Each case will have its `groups` array populated with recognition tags like:

  "groups": [
    "slot:FR",

    "edge_position:top",
    "level:beginner"

## Troubleshooting

### Error: "SUPABASE_SERVICE_KEY environment variable not set"

**Solution**: Make sure you've set the environment variable:
```bash
export SUPABASE_SERVICE_KEY='your-key-here'
echo $SUPABASE_SERVICE_KEY  # Verify it's set
```

### Error: "Failed to fetch from Supabase"

**Possible causes**:
1. Invalid or expired service key
2. Network connection issue
3. Supabase project is paused or unavailable

**Solution**: Check the Supabase dashboard and verify your project is active.

### Files not found

If you see warnings like "File not found", make sure you're running the script from the correct directory and that the seed data files exist.

## Alternative: Manual Export

If you can't get the service key or prefer manual export:

1. Go to Supabase Dashboard → SQL Editor
2. Run this query:
   ```sql
   SELECT code, groups
   FROM lib_cases
   WHERE groups IS NOT NULL AND groups != '{}'
   ORDER BY code;
   ```
3. Export as CSV
4. Manually update JSON files (or create a CSV import script)

## Technical Details

- **Source of Truth**: Supabase `lib_cases` table
- **Sync Direction**: Database → JSON (one-way)
- **Match Field**: `code` (case code like "F2L-1", "OLL-23", "Aa-Perm")
- **Groups Format**: Array of strings in `"category:value"` format
- **Script**: `export_groups_from_supabase.py`
